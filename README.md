# Introdução Alimentar - Landing Page Kit da Mamãe

Landing page responsiva de alta conversão clonada e otimizada a partir da página original [NutriBaby App](https://nutribabyapp.com.br/ebooksdesconto/).

## 📱 Recursos e Estrutura

- **HTML5 & CSS3**: Estrutura semântica e estilização completa extraída e otimizada para alto desempenho.
- **Recursos Locais**: Todas as imagens, arquivos CSS e JavaScript foram baixados e salvos localmente nas pastas `assets/`, `css/` e `js/` para independência total de servidor externo.
- **Responsividade**: Compatível com dispositivos móveis, tablets e desktop.
- **Checkout Integrado**: Botões de ação configurados para direcionamento rápido de checkout.

## 🚀 Como Executar

Basta abrir o arquivo `index.html` em qualquer navegador web ou servir através do GitHub Pages / Vercel.

## 📂 Estrutura de Arquivos

```
.
├── index.html        # Página principal
├── assets/           # Imagens e elementos gráficos
├── css/              # Folhas de estilo CSS
├── js/               # Scripts e interatividade JavaScript
└── README.md         # Documentação
```
